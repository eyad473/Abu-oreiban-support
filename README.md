# بوابة الدعم الفني للأهالي — مخيم أبو عريبان

هذا المجلد خاص بواجهة الأهالي فقط، وهو مناسب لمستودع GitHub مستقل وربطه بمشروع Cloudflare Pages مستقل.

## النشر
1. ارفع جميع الملفات الموجودة في هذا المجلد إلى جذر مستودع جديد، مثل `abu-oreiban-support-portal`.
2. أنشئ مشروع Cloudflare Pages واربطه بالمستودع.
3. اجعل مجلد البناء فارغًا (لا يوجد Build command) ومجلد الإخراج هو `/` أو الجذر حسب إعداد Cloudflare Pages.
4. الواجهة تتصل حاليًا بعنوان API: `https://moood.eyad2000515.workers.dev`.

## مهم
لن تعمل قراءة البيانات والتحقق وإرسال الطلبات حتى يتم نشر تحديث الـ Worker المرفق بشكل منفصل على الخادم الصحيح وربطه بقاعدة D1 الحالية. لا ترفع بيانات أسر أو أرقام هويات أو أرقام هواتف إلى هذا المستودع.
