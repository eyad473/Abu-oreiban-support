بوابة أهالي مخيم أبو عريبان – تحديث بطاقات أفراد الأسرة

محتويات الحزمة:
- index.html: واجهة البوابة بعد تحديث عرض أفراد الأسرة.
- sw.js: تحديث رقم التخزين المؤقت لإجبار المتصفح على تحميل النسخة الجديدة.
- manifest.webmanifest: ملف تعريف تطبيق الويب.

التعديلات المنفذة في بطاقات الأفراد:
1) إخفاء رقم الجوال البديل.
2) إخفاء المحافظة الأصلية.
3) إخفاء حالة السكن الأصلية.
4) إخفاء نوع السكن الحالي.
5) إخفاء إجابات «لا» وما يماثلها من صيغ النفي.
6) إظهار حقول المرض المزمن والإصابة والإعاقة فقط عندما تكون إجابة الحالة «نعم».
7) إظهار سبب الحالة وتفاصيلها فقط إذا كانت إجابة الحالة المرتبطة بها «نعم».
8) تحسين شكل بطاقة الفرد، مع إبقاء الاسم وصلة القرابة والبيانات الأخرى المسموح بعرضها.

النشر:
ارفع الملفات الثلاثة إلى جذر مستودع بوابة الأهالي على Cloudflare Pages واستبدل النسخ القديمة.
هذه حزمة واجهة فقط، ولا تحتوي على Worker، ولا تتطلب تعديل Worker أو قاعدة البيانات.
لا توجد عمليات حذف أو تعديل للسجلات الأصلية.
