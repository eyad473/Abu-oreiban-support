بوابة أهالي مخيم أبو عريبان — ملفات واجهة البوابة فقط

محتويات الحزمة:
- index.html: صفحة البوابة وواجهتها.
- sw.js: ملف Service Worker الخاص بتحديث التخزين المؤقت.
- manifest.webmanifest: إعدادات تثبيت البوابة على الهاتف.

طريقة الرفع:
ارفع هذه الملفات إلى مستودع بوابة الأهالي المرتبط بـ Cloudflare Pages واستبدل الملفات المناظرة فيه.

مهم:
- هذه الحزمة خاصة بواجهة بوابة الأهالي فقط.
- لا تحتوي على ملف Worker ولا تتطلب رفع أو تعديل Worker.
- لا ترفع هذه الملفات إلى مستودع التطبيق الرسمي أو مستودع Worker.
- لا تتضمن أي تعديل على قاعدة البيانات أو سجلات الأسر والأفراد والطلبات.
