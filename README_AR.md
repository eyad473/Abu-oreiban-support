بوابة أهالي مخيم أبو عريبان – المرحلة الأولى

محتويات الحزمة:
- index.html: واجهة البوابة ولوحة الأهالي ومركز الإشعارات ومساحة الإعلانات.
- sw.js: عامل الخدمة مع إصدار تخزين مؤقت جديد.
- manifest.webmanifest: تعريف تطبيق الويب.

ما تم تنفيذه في المرحلة الأولى:
1) لوحة رئيسية تظهر بعد التحقق الناجح، وتعرض حالة التحقق والاتصال.
2) اختصارات مباشرة إلى بيانات الأسرة وإرسال الطلب ومتابعته ومركز الإشعارات.
3) مركز إشعارات داخل الواجهة، يعرض إشعارات الجلسة مثل نجاح إرسال الطلب وتغير الاتصال.
4) مساحة مخصصة لإعلانات إدارة المخيم، وتعرض بوضوح عدم وجود إعلانات منشورة حالياً بدلاً من اختلاق إعلانات.
5) إبقاء صفحات البيانات والطلبات والمتابعة ومسارات Worker الحالية دون تغيير.
6) تحديث اسم ذاكرة التخزين المؤقت لضمان تحميل الإصدار الجديد.

ملاحظات التكامل:
- الحزمة واجهة أمامية فقط ولا تحتوي Worker.
- لم يتم تعديل قاعدة البيانات أو سجلات الأسر أو الطلبات.
- الإعلانات الحية والتنبيهات الإدارية الفورية تحتاج إلى واجهات API ومصدر بيانات معتمد؛ لم تتم إضافتها أو افتراض وجودها في هذا الإصدار.
- إشعارات المرحلة الحالية محلية للجلسة ولا تدّعي أنها تصل من إدارة المخيم.

النشر:
ارفع index.html وsw.js وmanifest.webmanifest إلى جذر مشروع Cloudflare Pages. بعد النشر افتح البوابة وأعد تحميلها.
