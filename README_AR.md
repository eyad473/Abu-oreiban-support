تحديث بوابة أهالي مخيم أبو عريبان — تصميم رسمي وفخم

محتويات الحزمة: index.html وsw.js وmanifest.webmanifest.

طريقة النشر:
1. افتح مستودع GitHub الخاص ببوابة الأهالي (وليس مستودع التطبيق الرسمي أو Worker).
2. استبدل ملفات البوابة الثلاثة الموجودة بهذه الملفات في جذر المستودع.
3. انتظر اكتمال نشر Cloudflare Pages.
4. افتح رابط البوابة من نافذة خاصة أو حدّث الصفحة بعد اكتمال النشر.

ما الذي تغير؟
- أصبحت شاشة التحقق برقم هوية رب الأسرة هي أول شاشة تظهر عند فتح الموقع.
- بعد إدخال الهوية، تظهر أسئلة التحقق الحالية من Worker؛ لا تظهر الخدمات قبل نجاح التحقق.
- بعد نجاح التحقق، تظهر واجهة الأهالي وخدمات عرض بيانات الأسرة وإرسال الطلبات ومتابعة حالة الطلب ورد الإدارة.
- تصميم RTL عربي رسمي متجاوب مع الهاتف، مع ألوان كحلية وتركوازية ولمسات ذهبية.
- تم تحديث إصدار Service Worker لإجبار المتصفح على تحميل النسخة الجديدة.

مهم جدًا:
- لا تستبدل ملف Worker/index.js ولا تعدّل قاعدة بيانات D1.
- لم تتغير عناوين API الحالية أو مسارات التحقق والطلبات، ولم تُجرَ أي عملية كتابة أو حذف لسجلات الأسر والتوزيعات.
- التحقق يستخدم المسار الحالي /support/challenge ثم /support/verify، ويعتمد على أسئلة التحقق الموجودة في Worker؛ هذه الواجهة لا تستبدل التحقق من جهة الخادم.
- اختبر ببيانات مصرح لك باستخدامها قبل نشر الرابط للأهالي.
