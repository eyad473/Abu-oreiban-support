بوابة أهالي مخيم أبو عريبان – المرحلة الثالثة

محتويات الحزمة:
- index.html: واجهة البوابة مع إضافات المرحلة الثالثة.
- sw.js: عامل خدمة بإصدار تخزين مؤقت جديد ودعم فتح الواجهة بعد تحميلها مرة واحدة.
- manifest.webmanifest: تعريف تطبيق الويب.

إضافات المرحلة الثالثة:
1) مساعد إرشادي محلي بأسئلة وأجوبة محددة حول التحقق، بيانات الأسرة، الطلبات، المتابعة، البطاقة الرقمية، الخريطة، والإعلانات. لا يستخدم ذكاءً اصطناعياً خارجياً، ولا يقرأ بيانات الأسرة أو يرسلها.
2) أدوات تسهيل الاستخدام: تكبير وتصغير الخط، إعادة الحجم الطبيعي، تباين مرتفع، وتقليل الحركة.
3) قراءة قسم الإعلانات صوتياً عبر ميزة تحويل النص إلى كلام المدمجة في المتصفح، إذا كان الجهاز والمتصفح يدعمانها.
4) دعم فتح واجهة البوابة والإرشادات المخزنة مؤقتاً بعد زيارة الموقع مرة واحدة أثناء الاتصال.
5) توضيح ما يعمل دون اتصال: الإرشادات والواجهة فقط. التحقق من الهوية وجلب بيانات الأسرة وإرسال الطلبات ومتابعتها تحتاج اتصالاً بالخادم.

الخصوصية والأمان:
- لا توجد طوابير محلية لطلبات الأسر ولا تخزين محلي لأرقام الهوية أو أرقام الجوال أو بيانات الأسرة.
- المساعد الإرشادي لا يصل إلى كائن بيانات الأسرة أو رمز جلسة التحقق ولا يرسل أي محتوى إلى الخادم.
- لم تتم إضافة سجل المساعدات.
- لم يتم تعديل Worker أو قاعدة البيانات أو سجلات الأسر.
- بقيت مسارات التحقق والطلبات والمتابعة كما هي.
- الحزمة واجهة أمامية فقط ولا تحتوي ملفات Worker.

حدود النسخة:
- المساعد إرشادي محلي محدود بالإجابات المكتوبة داخله، وليس مساعداً ذكياً متصلاً بإدارة المخيم.
- قراءة الإعلانات تعمل على النص الظاهر حالياً. لا توجد إعلانات منشورة في المصدر الحالي.
- لا يمكن إكمال المعاملات الحساسة دون اتصال بالإنترنت.

النشر:
1) احتفظ بنسخة احتياطية من إصدار المرحلة الثانية.
2) استبدل ملفات index.html وsw.js وmanifest.webmanifest في جذر مشروع Cloudflare Pages.
3) انشر المشروع ثم افتح البوابة مرة واحدة أثناء توفر الإنترنت لتخزين الواجهة.
4) إذا استمرت نسخة قديمة بالظهور، أغلق التطبيق/التبويب وافتحه مجدداً بعد تحديث عامل الخدمة.

لم يتم نشر التحديث على Cloudflare من هذه الحزمة.
