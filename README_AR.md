بوابة أهالي مخيم أبو عريبان – تحديث تنظيم الرئيسية والبطاقة والإشعارات

الملفات:
- index.html: الواجهة بعد التعديلات.
- sw.js: عامل الخدمة مع رفع رقم إصدار التخزين المؤقت إلى المرحلة الرابعة.
- manifest.webmanifest: تعريف تطبيق الويب كما في النسخة السابقة.
- worker_index_notifications.js: نسخة Worker API بعد إضافة مسار الإشعارات للأسرة.

التعديلات المنفذة في الواجهة:
1) الرئيسية تعرض قسم إعلانات إدارة المخيم وبطاقة الأسرة الرقمية فقط.
2) البطاقة تعرض الاسم الرباعي لرب الأسرة، رقم الهوية، عدد أفراد الأسرة، ورقم الجوال.
3) إلغاء الطباعة ونسخ البطاقة، واستبدالهما بتنزيل صورة PNG عبر زر واحد.
4) إنشاء قسم مستقل بعنوان «معلومات السكن والأسرة» يعرض المحافظة الأصلية وحالة السكن الأصلي ونوع السكن الحالي فقط، بعيداً عن بطاقات الأفراد. وتبقى أي بيانات أسرية إضافية في قسم منفصل.
5) ترتيب بيانات كل فرد: الاسم، صلة القرابة، رقم الهوية، تاريخ الميلاد، العمر، ثم بقية التفاصيل. ويُحسب العمر عند غيابه إذا كان تاريخ الميلاد واضحاً.
6) إزالة تبويب متابعة الطلب المستقل، واستبداله بتبويب الإشعارات.
7) الإشعارات تعرض رد الإدارة وتغيّر حالة الطلب، وتُحدّث دورياً كل 45 ثانية أثناء فتح البوابة، كما تُجلب عند تسجيل الدخول وفتح تبويب الإشعارات.
8) نقل دليل موقع المخيم إلى قسم بياناتي حتى لا يظهر ضمن الرئيسية.

تحديث Worker API المطلوب للإشعارات:
- ملف worker_index_notifications.js هو كود Worker API الكامل المأخوذ من مصدر Worker المتاح، مع إضافة GET /support/notifications.
- الواجهة الحالية ترسل طلبات API إلى https://moood.eyad2000515.workers.dev؛ لذلك يجب تحديث Worker الخاص بهذا العنوان، وليس Worker الذي يعرض صفحة البوابة https://abu-oreiban-support.eyad2000515.workers.dev.
- تمت إضافة مسار قراءة فقط يتحقق من X-Support-Session ثم يعيد طلبات الأسرة المرتبطة بجلسة التحقق فقط.
- أُضيف فهرس D1 إضافي على family_id وupdated_at لتحسين البحث؛ لا يحذف أو يعدل أي سجل قائم.

خطوات النشر المقترحة:
1) احتفظ بنسخة احتياطية من ملفات الواجهة الحالية وكود Worker الحالي.
2) حدّث Worker API في مشروع moood باستخدام worker_index_notifications.js وانشره. لا تضع هذا الملف في مجلد الأصول الثابتة.
3) حدّث ملفات الواجهة في مشروع استضافة البوابة abu-oreiban-support باستخدام index.html وsw.js وmanifest.webmanifest.
4) انشر الواجهة، ثم افتح البوابة من هاتفك بعد النشر وأعد التحقق من أسرة تجريبية مصرح بها.
5) اختبر: ظهور الحقول الأربعة على البطاقة، تنزيل PNG، ترتيب بيانات أفراد الأسرة، إرسال طلب تجريبي، ثم تحديثه من لوحة الإدارة والتحقق من ظهور الرد في الإشعارات.

ملاحظات وحدود مهمة:
- لم يتم نشر أي شيء على Cloudflare من هذه الحزمة، ولا أملك تأكيداً أن النسخة الحية تغيرت. يلزم تنفيذ خطوات النشر أعلاه.
- الإشعارات داخل البوابة تُحدّث أثناء بقاء الصفحة مفتوحة، وتُجلب مجدداً عند الدخول. لا يوجد في هذه النسخة Push Notification إلى الهاتف عندما تكون البوابة مغلقة؛ ذلك يحتاج إعداد Web Push منفصل.
- المتصفح لا يضمن حفظ الملف مباشرة في تطبيق المعرض؛ زر PNG ينزّل صورة عادية، وقد تظهر في التنزيلات أولاً حسب نوع الهاتف والمتصفح.
- لم يتم تغيير جداول بيانات الأسر أو سجلات التوزيع. التغيير في D1 مقتصر على إنشاء فهرس إضافي آمن وجدول الطلبات الموجود مسبقاً لا يتغير.
- لم تتم إضافة مساعد Gemini أو أي خدمة ذكاء اصطناعي.
